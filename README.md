# 中學生涯規劃 · 資料站

香港中學生涯規劃教育的完整整理。純靜態網頁，零外部依賴，可直接以 GitHub Pages 發佈。

## 內容

- **定位** — 不是選科服務，而是決策能力；政策文件、專用津貼、向高小延伸
- **三個元素**（可切換分頁）— 自我認識及發展／升學事業探索／升學事業規劃與管理
- **校內安排** — 中一至中六的六年路線圖（標明屬常見做法）；升學就業輔導組、統籌教師、六項原則
- **出路數據** — 2024／2025 中六畢業生出路對照表；2026 聯招申請與取錄柱圖
- **支援計劃** — 商校合作、工作體驗、應用學習、OLE、師友與 NGO、家長教育
- **特殊組群** — SEN、非華語、基層、成績邊緣學生
- **家長四個角色**、**五個爭議**、**10 條 FAQ**、**4 項限制**、**10 項來源**

## 技術

`index.html` / `assets/style.css` / `assets/app.js`；無框架、無 CDN、無追蹤碼。
視覺：赭橙 + 深藍灰，六年進程以鐵路線式 stepper 呈現；含進度條、scroll spy、元素分頁（支援左右方向鍵）。

## 重要說明

《中六學生出路統計調查》的百分比以「有回應的畢業生」為分母，並非全港中六學生總數。
津貼金額按年調整，本頁只列計算基準與一個已公開的年度例子。政策以教育局指引及通函為準。
